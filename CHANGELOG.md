# Changelog

## 0.1.0

- First release. Opens MessagePack (.msgpack, .mpk), BSON (.bson) and CBOR (.cbor) files as a tree with types, sizes and byte offsets, including files with many values one after another.
- Shows ext types, timestamps, CBOR tags, ObjectIds, dates, decimal128 and binary data clearly.
- JSON view with copy, Copy value and Copy path, and search of keys and values.
- Bad data shows its byte offset with a plain note, and every value before it still shows.
- Zovo Pro tools: Convert to JSON and from JSON, Edit a value and save, Compare two files, Batch convert a folder to JSON (1 free try each).
