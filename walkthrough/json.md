# JSON view, copy and search

- Click JSON in the viewer toolbar. The selected value shows as JSON; with nothing selected, the whole file shows.
- Copy JSON copies all of it, up to 50 MB. The view shows the first 2 MB of a very large value.
- In the details on the right, Copy value copies a text value as it is (other values as shown), and Copy path copies the path, such as `#2.items[0].sku`.
- Type in the search box to find keys and values anywhere in the file. A click on a match opens the values above it and selects it.
