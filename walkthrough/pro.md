# Zovo Pro tools

Each tool has 1 free try on your computer. After that, a click on the tool opens the Zovo Pro panel.

- Convert to JSON and from JSON: plain JSON, typed JSON (converts back to the same types), JSON Lines, or one of the other two formats. Run it on a JSON file to turn it into MessagePack, CBOR or BSON.
- Edit a value and save: click a value, then Edit value (Pro) in its details. Save into the file or into a copy. Every other value keeps its exact bytes.
- Compare two files: pick the second file; the differences show with their paths, and Save report as Markdown writes them out.
- Batch convert a folder to JSON: each file in the folder gets `<name>.json` next to it.

Zovo Pro is USD 19 once for the Pro tools in every Zovo extension.
